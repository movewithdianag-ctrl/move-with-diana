# Images — how to replace the placeholders

Drop Diana's real photos into this folder using **exactly these filenames**
and the site updates with **zero code changes**. All sizes below are 2× for
retina screens; JPG at ~80% quality keeps files fast on mobile data.

| Filename             | Used where                          | Aspect ratio                  | Recommended size (px) |
| -------------------- | ----------------------------------- | ----------------------------- | --------------------- |
| `hero-home.jpg`      | Home hero                           | 16:9 desktop, cropped 4:5 on mobile | **2400 × 1350** |
| `intro-portrait.jpg` | Home "Meet Diana" portrait          | 4:5 portrait                  | **1600 × 2000**       |
| `about-portrait.jpg` | About page hero portrait            | 4:5 portrait                  | **1600 × 2000**       |
| `offer-private.jpg`  | Offers — Private Pilates 1:1        | 3:2 landscape                 | **1800 × 1200**       |
| `offer-semi.jpg`     | Offers — Semi-private (2–4)         | 3:2 landscape                 | **1800 × 1200**       |
| `offer-group.jpg`    | Offers — Group classes              | 3:2 landscape                 | **1800 × 1200**       |
| `offer-community.jpg`| Offers — Join the community         | 3:2 landscape                 | **1800 × 1200**       |

(`offer-program.jpg` is no longer used — the customized-programs offer was
removed. The file can stay or be deleted. A future "movements" gallery will
need `movement-1.jpg` … `movement-6.jpg`, 3:2 or 4:5, once that section is
designed.)

Tips for choosing crops:

- **hero-home.jpg** is shown wide (16:9) on desktop but cropped to a tall 4:5
  on phones — keep Diana and the action in the **center** of the frame so both
  crops work. Almost all visitors are on phones.
- Portraits (4:5): head-and-torso framing, eyes in the upper third.
- Every image is displayed with `object-fit: cover`, so slightly larger photos
  are fine — they'll be cropped, never stretched.
- Natural light, warm tones, and real training moments fit the site's palette
  (warm plaster, espresso, spring-steel blue).
